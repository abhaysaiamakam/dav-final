# Phase 1 Python Code Explorer audit

The Code Explorer source manifest is generated by `scripts/build-codelens-manifest.py` from a fixed symbol allowlist and Python AST. `apps/web/src/lib/phase1-python-sources.json` is a build artifact. `pnpm --dir apps/web dev` and `pnpm --dir apps/web build` regenerate it through their existing pre-hooks. Each displayed function body is copied verbatim from the cited repository path; Raw Python removes only comment-only lines while preserving source line positions. The module import block is copied from that same file. Production method excerpts are not represented as a synthetic, independently runnable script.

## Explicitly unavailable or separate

- No t-SNE, UMAP, Isolation Forest, or Z-score/robust-Z-score outlier implementation is represented in this Phase 1 image pipeline.
- Canny exists as an on-demand display preview; it is not a stored dataset-wide Canny feature in the selected image-intelligence run.
- Image feature-registry PCA is not available in the current image-modality feature registry. The displayed production PCA is the separate image-intelligence feature pipeline.
- Image previews and preprocessing implementations do not imply that an operation was applied to the original ICAR version. Applying preprocessing uses derived-version handling.
- No disease classifier, training metrics, or disease diagnosis is implemented by these analysis functions.
